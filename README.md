# 📊 Sales Data Analysis Project

> A complete end-to-end data analysis project: **data generation → cleaning → analysis → visual dashboard → business insights**.

Built by **Srinu Ravuri** — Aspiring Data Analyst | B.Tech Information Technology

## 📌 Overview

This project analyzes **3 years of Indian retail sales data** (2022–2024) and answers real business questions:

- How are sales and profits trending over time?
- Which categories, regions and products drive revenue?
- Where are we losing margin, and why?
- What should the business do next? (actionable recommendations)

Everything is **reproducible**: the dataset is generated by `scripts/generate_data.py`, so anyone can regenerate it with the same random seed.

## 📁 Project Structure


## 🚀 How to Run

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Generate the dataset (optional — sales_data.csv is already included)
python scripts/generate_data.py

# 3. Run the full analysis
python scripts/analysis.py

# 4. Open the dashboard
#    → output/dashboard.html  (just double-click / open in browser)
```

## 🔍 Key Findings (from the included dataset)

Full report: **`output/summary_report.md`**. Highlights from this run:

- 💰 **Total revenue ₹26.9 Cr** over 3 years (5,000 orders, 12.4% profit margin)
- 📈 Revenue **grew 6.8%** year-over-year (2023 → 2024)
- 🏆 **Electronics** is the top revenue category but runs the thinnest margin (9.2%) — volume vs. profitability trade-off
- 🗓️ Strongest month: **Oct 2023** — Indian festival-season demand (Diwali ~ Oct/Nov)
- 🌏 **East India** leads regional sales; **North** lags — expansion opportunity
- 🎯 4 actionable business recommendations in the report
